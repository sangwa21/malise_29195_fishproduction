## 1. Project Background
Rwanda's fish production sector includes capture fisheries and aquaculture. Analyzing production data over time can help identify trends and support better planning and sustainable fisheries management.

## 2. Problem Statement
Fish production information needs to be organized and analyzed to make it easier to understand production trends, changes, and possible unusual variations over time.

## 3. Project Aim
To develop an Oracle PL/SQL database system that stores, manages, and analyzes fish production data in Rwanda.

## 4. Project Objectives
- Store fish production data in a structured database.
- Analyze production trends over different years.
- Identify unusual changes in production.
- Generate useful reports using PL/SQL.
- Present results through an interactive Oracle APEX dashboard.

## 5. Data Source
The project will use the FAO FishStat global aquaculture and fisheries production statistics.

Dataset: https://www.fao.org/statistics/data-collection/fishery-and-aquaculture/en

The Rwanda country code is 646 in the downloaded dataset. The applicable data licence and attribution requirements will be checked before use.

## 6. Project Innovation
The project will provide an interactive, database-connected Oracle APEX dashboard for exploring Rwanda's fish production trends and viewing analytical results.

## 7. Proposed Database Tables
- COUNTRIES
- SPECIES
- PRODUCTION_TYPES
- PRODUCTION_RECORDS

## 8. Planned SQL and PL/SQL Features
- SQL queries and joins
- Stored procedures and functions
- Explicit and implicit cursors
- Records and collections
- Exception handling
- Transaction control
- Data analysis and reporting

## 9. Expected Output
A functional Oracle database system with PL/SQL operations and an interactive Oracle APEX dashboard for monitoring fish production data.
